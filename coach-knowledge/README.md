# Coach knowledge

Plain-language training knowledge the coach uses to build and adjust plans for any client and goal.

| File | What it is |
| --- | --- |
| `planning-playbook.md` | How to build a plan: intake, weekly sets by goal, effort, progression, deloads, look goals, checklist |
| `recommendation-guide.md` | If-then advice for client feedback (glutes, thrust fixes, hamstrings, upper body, recovery, equipment) |
| `exercise-a-to-z.md` | Alphabetical exercise list with target, level, equipment and notes, plus a find-by-need table |

General fitness guidance, not medical advice.
