# Coach Tracker

The newest version of the Training Log tracker page from the Build Your Own Coach kit.

If you have the kit, you don't need to download anything here yourself. Open Claude and say "update my tracker". Your coach checks this folder, and if a newer version is here, it updates your tracker on the same link. Your food, workouts, weigh-ins and photos stay exactly as they are.

- `tracker-template.html`: the tracker page
- `version.json`: the current version number and what changed
